# Co-Work Quick Start Checklist

A step-by-step checklist to set up and run the Co-Work application.

## ✅ Phase 1: Prerequisites
- [ ] Node.js 18+ installed
- [ ] npm or bun installed
- [ ] Google Gemini API key obtained

## ✅ Phase 2: Configuration
- [ ] Copy `.env.example` to `.env`
- [ ] Add `GEMINI_API_KEY=your_key_here` to `.env`

## ✅ Phase 3: Setup & Run
- [ ] Install dependencies: `npm install`
- [ ] Start development server: `npm run dev`
- [ ] Open application in browser: `http://localhost:3000`

## ✅ Phase 4: Test Co-Work Features
- [ ] Sign in to workspace interface
- [ ] Check Daily Briefing panel
- [ ] Test intelligent chat assistant
- [ ] Check Calendar, Tasks, Notes, and Email Draft Console

## ✅ Phase 5: Production Build & Deployment
- [ ] Run production build: `npm run build`
- [ ] Test production server: `npm start`
- [ ] Deploy with GitHub Pages or Cloud Run
